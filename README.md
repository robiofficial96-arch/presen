# Our Builders Ltd. - Times Square Green Condominium Presentation

An interactive, presentation deck built for **Our Builders Ltd.** showcasing the **Times Square Green Condominium** project.

## Features & Highlights
- **11 Interactive Slides** with smooth navigation, transitions, audio voiceovers, and background music.
- **Slide 1**: Brand Hero & Logo Intro
- **Slide 2**: MD Profile (Sayed Hafiz Monir) with interactive letter envelope unfolding animation
- **Slide 3**: 21-Story Green Condominium Overview
- **Slide 4**: Mega Project Highlights (40 Katha, 252 Luxury Flats)
- **Slide 5**: Prime Location Map (Madanpur-Kanchpur Highway)
- **Slide 6**: Smart Automated Basement Parking & Luxury Lifestyle Facilities Scrubber
- **Slide 7**: Residential Interior Showcase (Drawing Room, Dining Room, Master Bedroom, Balcony, Luxury Bathroom)
- **Slide 8**: Safety & Infrastructure Showcase (24/7 CCTV, Power Backup Generator, Smart Lifts, Fire Safety, Water Filtration)
- **Slide 9**: Ongoing & Upcoming Projects Portfolio
- **Slide 10**: Agreement Ceremony Booking Mega Offers & Savings
- **Slide 11**: Grand Finale & Share Booking Celebration with Confetti

## How to Run
Simply open `index.html` or `times_square_presentation.html` in any modern web browser.
